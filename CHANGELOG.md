# Changelog

All notable changes follow [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and this project uses semantic versioning.

## [Unreleased]

## [0.2.0] - 2026-10-18
### Changed
- Replaced the initial minimal mapper with a `flint-chart@0.5.1` contract-backed compiler.
- Added the complete 44-template public Flint registry union, strict per-template validation,
  static-series normalization, aggregation, semantic/temporal resolution, themes and interactions.
- Added conformance tests for every official Flint gallery fixture.

## [0.1.0] - 2026-10-18
### Added
- Typed Flint-to-VChart compiler, validator, semantic inference and diagnostics.
- 16 VChart template families plus common Flint aliases.
- Inline/URL data, sizing, title, display-name, sorting and theme conversion.
- Vitest suite, dual ESM/CJS package build and declaration output.
- Interactive Vite playground and GitHub Pages workflow.
- npm provenance release workflow and complete package documentation.
